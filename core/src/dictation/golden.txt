# [unchanged]  Each line is text that is right as it stands. `clean` must give it back exactly as it is: a rule that damages correct text is worse than no rule,
#              because the text goes into a document nobody looks at first.
# [tidy]       Each line is `what was heard -> what must come out`: fillers, stutters, a missing capital, a space before a stop.
#
# Written once from the failures people have (a "cancel that" in the middle of a sentence, "ER" the room, ".env" the file, "i.e." the abbreviation); add a line
# when a new damage is found, and fix the rule.
